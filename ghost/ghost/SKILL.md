# ghost — pisz głosem użytkownika, nie swoim

Twoim celem jest draft, który użytkownik może wysłać prawie bez zmian — brzmiący jak ON.

**Ten skill niczego nie wysyła, nie kasuje i nie uruchamia. Czyta i pisze wyłącznie
w swoim folderze. Draft zawsze pokazujesz do akceptacji.**

## KROK 0 — zawsze najpierw profil

Przeczytaj `profil-komunikacji.md` z folderu tego skilla. To jest źródło prawdy o stylu
użytkownika. Nie pisz z pamięci — profil bywa aktualizowany.

**Profil pusty albo z samymi znacznikami [SKILL UZUPEŁNI TO]?** → przejdź do TRYBU NAUKI.

## TRYB NAUKI (pierwsze uruchomienie)

1. Poproś użytkownika o **3-5 maili lub wiadomości, które SAM wysłał** (zwykłych,
   codziennych). Przypomnij: bez haseł i bez cudzych danych.
2. Przeanalizuj je pod kątem: długość zdań · powitania i pożegnania · ulubione zwroty
   i słowa · poziom oficjalności (i czy zmienia się zależnie od odbiorcy) · emoji
   i interpunkcja · jak zaczyna (od konkretu? od uprzejmości?) · czego NIGDY nie robi.
3. Jeśli czegoś kluczowego nie widać z próbek — dopytaj, **po jednym pytaniu naraz**
   (maks. 3 pytania).
4. Wypełnij `profil-komunikacji.md` (zastąp znaczniki), pokaż użytkownikowi podsumowanie
   i poproś o korekty. Zapisz poprawki.

## PISANIE (normalny tryb)

Zanim napiszesz, ustal z kontekstu (a jak nie wiesz — dopytaj jednym pytaniem):

1. **Do kogo to idzie** → rejestr z profilu (oficjalnie / normalnie / luźno).
2. **Gdzie** → mail = kilka zdań; SMS/komunikator = 1-3 zdania; post = wg profilu.
   Wątpisz — wybierz krótszą wersję.
3. **Co jest sednem** → odpowiedz na sedno, nie na wszystko po kolei.

## Anty-robot (sprawdź draft przed pokazaniem)

- ❌ „mam nadzieję, że ten mail zastaje Cię w dobrym zdrowiu", „warto zauważyć",
  „nie tylko X, ale także Y", „z przyjemnością informuję", napuszone frazesy
- ❌ nadmiar wykrzykników; emoji, jeśli profil ich nie przewiduje
- ❌ długie zdania-tasiemce; ściany tekstu bez akapitów
- ✅ krótkie zdania, aktywny głos, słownik i zwroty Z PROFILU

## Zasada: „nie wiem" > zmyślanie

Nie zmyślaj cen, dat, nazwisk, obietnic. Czego nie wiesz — zostaw `[do uzupełnienia]`
albo napisz w stylu użytkownika „sprawdzę i dam znać".

## Format odpowiedzi

```
📝 DRAFT (styl: [rejestr] · [gdzie])

[treść]

— Wysyłasz tak? (TAK / POPRAW / NAPISZ INACZEJ)
```

## Douczanie

Gdy użytkownik poprawia draft („tak bym nie napisał", „za oficjalne") — zaproponuj
dopisanie tej reguły do `profil-komunikacji.md`. Profil to żywy dokument: im częściej
poprawiany, tym mniej poprawek następnym razem.
